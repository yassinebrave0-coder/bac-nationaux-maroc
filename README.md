# BAC Nationaux - Sciences Physiques (Français)

Tous les examens nationaux du Baccalauréat (Maroc) pour la filière **Sciences Physiques - Section Française**.

## Contenu

- **preuves/** : Sujets d'examens (2016-2024)
  - Mathématiques, Physique-Chimie, SVT, Philosophie, Anglais
  - Sessions : Normal + Rattrapage
- **corrections/** : Corrigés d'examens (2016-2024)
  - Même structure que les preuves

## Structure

```
nationaux/
├── preuves/
│   ├── {matiere}/
│   │   ├── normal/
│   │   └── rattrapage/
├── corrections/
│   ├── {matiere}/
│   │   ├── national/
│   │   ├── normal/
│   │   └── rattrapage/
└── README.md
```
